# Student Performance Analysis and Prediction

## Project Overview
This project analyzes student performance using Python,
data visualization, and machine learning.

## Features
- Student dataset analysis
- Statistical summaries
- Grade distribution visualization
- Machine learning model for grade prediction
- Interactive Streamlit dashboard

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit

## Dataset
UCI Student Performance dataset:
https://archive.ics.uci.edu/dataset/320/student+performance

## Run Locally
1. Install the required packages:
   pip install -r requirements.txt

2. Train the model:
   python train_model.py

3. Start the dashboard:
   streamlit run app.py

## Disclaimer
Predictions are estimates for educational purposes
and are not guaranteed actual student grades.
